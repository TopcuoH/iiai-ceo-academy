# IIAI CEO Academy

Практическая персональная MBA-подобная программа CEO без академической воды.

- 21 модулей
- 84 практических уроков
- темы: стратегия, продукт, финансы, найм, онбординг, делегирование, оргструктура, KPI/OKR, performance, one-to-one, увольнения, конфликты, руководители руководителей, культура и выгорание, решения, кризисы, масштабирование 10→100→1 000→10 000, governance и AI-first управление
- весь прогресс хранится локально в браузере через `localStorage`
- статический сайт: достаточно GitHub Pages, Cloudflare Pages, Netlify или любого статического хостинга

## Локальный запуск

Откройте `index.html` в браузере. Для полноценной работы рекомендуется простой локальный HTTP-сервер:

```bash
python -m http.server 8080
```

Затем откройте `http://localhost:8080`.

## GitHub Pages

Settings → Pages → Deploy from a branch → `main` / root.
